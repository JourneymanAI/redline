# 16: Library

**What to build:** Every completed review auto-saves to the signer's library:
the document text, the structured analysis, the governing-law answers, and a
timestamp — never the original file. A returning signer lands on their
library. They can search or filter past reviews, reopen one to see identical
flags/source sentences/counter-offers (re-verified against the same stored
text), delete a review, and re-run a stored document against their current red
lines.

- [ ] Completing a review saves it automatically with text, analysis,
